# Сайт учебного наставничества Никиты Созонова

Статический одностраничный сайт без внешних зависимостей. Подходит для публикации на GitHub Pages.

## Локальный просмотр

Откройте `index.html` в браузере или запустите любой локальный HTTP-сервер из этой папки.

## Публикация на GitHub Pages

1. Создать публичный репозиторий.
2. Загрузить в него содержимое этой папки.
3. В настройках репозитория открыть **Pages**.
4. Выбрать публикацию из ветки `main`, каталог `/ (root)`.

Основные контакты и цены находятся в `index.html`. Визуальные настройки — в `styles.css`.
